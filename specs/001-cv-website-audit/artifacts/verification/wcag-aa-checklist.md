# WCAG 2.2 AA Verification Checklist

## Scope
- Primary pages: `index.md`, `resume.md`, `projects.md`, `skills.md`
- Shared layouts/components: `_layouts/default.html`, `_layouts/resume.html`, `assets/css/style.scss`

## Checks
- Semantic headings follow logical order.
- Images and icons have meaningful alternative text or are correctly hidden from assistive tech.
- Interactive elements are keyboard reachable and visibly focusable.
- Link purpose is clear from text/context.
- Color contrast meets WCAG 2.2 AA expectations for text and UI controls.
- Document language and metadata are correctly declared.
- No essential content depends on JavaScript execution.
